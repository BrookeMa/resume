Architecture

AI Streaming Narration

OpenAI-powered narrator generates branching storylines in real time via SSE streaming. Players respond with free-text input — no predefined choices — and the AI adapts the narrative based on context and story arc progression.

Story Engine

Multi-act story arc system with StoryWorld templates defining characters, prologues, and branching points. AuthContext + StoryContext manage state across discovery, trial play, and full story sessions.

Trial & Monetization

Free prologue (~10 rounds) with no account required. Full stories via one-time purchase or round credits. Stripe Checkout + Webhooks handle payments, and round balance tracks usage.

UI & Design System

66 components built with Radix UI + Tailwind + CVA variants. Gothic dark theme with Playfair / Cormorant display fonts, Motion animations, and responsive mobile layouts.

Content & Blog

20 Markdown blog posts with gray-matter frontmatter parsing and marked rendering. Rich text editing via TipTap for story creation. Discover page with categorized story templates.

Security & Monitoring

CSP headers, rate limiting, Supabase Auth with cookie-based sessions. Sentry error tracking, Vercel Analytics, and production console stripping with error-only preservation.

Key Modules

  • db.ts Data Layer — Supabase + native pg pool wrapper handling story CRUD, state persistence, purchases, and round credit management.
  • discover-templates.ts Content — Story world metadata, character definitions, prologues, and ALL_STORIES catalog powering the discovery page.
  • story-arcs.ts Engine — Multi-act narrative structure driving story progression, branching points, and arc-based pacing.
  • model-prefs.ts AI — Configurable OpenAI model preferences with environment-based overrides for narration quality tuning.
  • rate-limit.ts Security — Request rate limiting per endpoint to prevent abuse of AI streaming routes.
  • AuthContext.tsx State — Global authentication state with Supabase session management, cookie sync, and protected route gating.
  • StoryContext.tsx State — Story session state: current story, progress, messages, arc position, and save/load coordination.
