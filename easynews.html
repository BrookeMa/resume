Features

Top Headlines UI

Grid-based news feed powered by the Mediastack API. Uses UICollectionView with image prefetching and pull-to-refresh.

Article Reader WebKit

Full-article reader using WKWebView for in-app browsing. Opens article URLs without leaving the app context.

Image Loading Async

Cell-level image lifecycle management with RemoteImageDataLoader. Cancels in-flight requests on cell reuse for optimal memory usage.

Offline Cache Core Data

Framework-level article caching via CoreDataArticleStore and LocalArticlesLoader with schema migration support.

Localization i18n

English and Simplified Chinese support with .strings files and a typed Localized helper for compile-time safety.

CI Scheme Quality

Dedicated CI.xcscheme with code coverage enabled for automated testing in continuous integration pipelines.

Key Design Decisions

  • Protocol-based Abstractions — HTTPClient, ArticleLoader, and ArticleStore are all protocols, enabling test doubles, decorator patterns, and flexible composition.
  • Composition Root — All dependency wiring happens in SceneDelegate via TopHeadlineUIComposer, keeping view controllers free of infrastructure concerns.
  • MainQueueDispatchDecorator — Wraps loaders to guarantee UI updates dispatch to the main thread, without polluting business logic with DispatchQueue.main calls.
  • Framework Separation — EasyNewsFeature has zero UIKit imports, enforcing a platform-agnostic domain and networking layer that could be reused across iOS, macOS, or watchOS.
  • Cell Controller Pattern — Each cell type has its own controller (TopHeadlineCellController, TopHeadlineImageCellController) managing its own lifecycle, image loading, and cancellation.
  • URLProtocol Stubbing — Network tests use URLProtocolStub to intercept requests at the URL loading system level, testing real URLSession behavior without hitting the network.
