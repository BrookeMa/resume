Video Player Module

A 4-month development effort delivering a full-featured video player SDK. Two base styles plus a universal custom style, compatible with two gallery layouts. Supports embedded playback, cell-level playback, and CRN (Ctrip React Native) integration.

  • Dual Gallery Support — Compatible with two distinct gallery layouts, with seamless switching and custom transition animations.
  • Cell Playback — Inline video playback within scrolling list cells (UITableView/UICollectionView) without interrupting scroll UX.
  • CRN Integration — Packaged as a native module callable from Ctrip React Native pages, bridging native performance with RN flexibility.
  • Frame-based Animations — Replaced Auto Layout constraints with manual frame calculations for transition animations to eliminate CPU-bound frame drops.
  • Gesture & Rotation — Full gesture support (swipe, pinch, tap) and device rotation handling with custom button icons using vector graphics.
  • Cross-team Adoption — Integrated by Hotels, Activities, Car Rental, and Tickets teams with per-team customization interfaces.

CRN — Ctrip React Native

Contributed to the development of CRN, Ctrip's open-source cross-platform framework based on React Native — optimized for stability and performance at scale. 1.5k GitHub Stars, 203 Forks.

Bundle Splitting Core

Framework and business code are split into separate bundles, enabling independent deployment and shared framework preloading across all business modules.

Background Preloading Performance

Framework bundle is preloaded in the background before users navigate to RN pages, reducing first-screen load time by ~50% on iOS and ~60% on Android.

Incremental Compilation Build

Module IDs remain stable across builds for the same module, enabling incremental packaging and faster CI/CD turnaround.

Unified Build Artifacts Cross-platform

A single set of build artifacts shared between iOS and Android, reducing maintenance overhead and ensuring cross-platform consistency.

LazyRequire Optimization

Deferred module loading to minimize initial bundle execution time, only loading modules when they are actually needed.

CRN-CLI Tooling

Custom CLI toolchain (crn-cli) published to npm for project scaffolding, development, debugging, and packaging workflows.
