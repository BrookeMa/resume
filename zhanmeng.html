Library Details

ZM_BaseLib Foundation

Core utility library with 30+ categories on Foundation & UIKit classes, plus reusable tools: ZMFileManager, ZMDateManager, ZMLocationManager, ZMRegexManager, ZMNavigationBar, ZMActionSheet, ZMNetTools, ZMBaseButton.

ZM_Networking Network

Network abstraction layer built on AFNetworking. Custom XESNetwork request engine with unified API, response model mapping via MJExtension, and centralized error handling.

ZM_DataBase Persistence

Database component wrapping FMDB with schema migration support via FMDBMigrationManager. Provides ZMDataBase singleton, ZMDataBaseTool helpers, and ZMMigration version control.

ZM_ThirdPartyLibraryExpand Router

URL-based routing system using JLRoutes with custom ZMRouterTools, ZMRouterPath, and ZMRouterModel. Integrates YYKit utilities and UMeng analytics & social sharing (WeChat, QQ, Weibo).

ZM_Notepad_BaseLib Product

"XiaoHei" notepad product base library. Aggregates all ZM modules plus MMDrawerController (side menu), MBProgressHUD, Toast, UICKeyChainStore for secure credential storage.

Key Components

  • ZMFileManager — File system abstraction for sandboxed document management, caching, and temporary file operations.
  • ZMLocationManager — CoreLocation wrapper for location-based features with permission handling and geocoding.
  • ZMNavigationBar — Custom navigation bar component with flexible styling, overriding default UINavigationBar behavior.
  • XESNetwork — Centralized HTTP client with request queuing, response serialization, and unified error callbacks built on AFNetworking.
  • ZMRouterTools — App-wide URL routing for decoupled page navigation. Uses ZMRouter.plist for route registration and ZMRouterModel for parameter passing.
  • ZMMigration — Database version management ensuring safe schema upgrades across app updates without data loss.
  • WebViewJavascriptBridge — Native-to-H5 bridge for hybrid pages, enabling seamless communication between Objective-C and embedded web views.
  • 30+ Categories — Extensions on NSString, NSDate, UILabel, UIColor, UIView, NSDictionary, etc. for consistent utility methods across the codebase.
