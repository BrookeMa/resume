Design System Overview

The brand & UI design system for Toonlife — a sun-drenched coastal cartoon-city life-sim on Roblox. The game's in-engine UI (its Luau UIKit) was reverse-engineered from source, not screenshots, and ported 1:1 to the web — so designers can mock screens, marketing, and pitch material that look exactly like the shipped game. One UI language, three platforms: the panels, buttons, and chrome are identical everywhere; only the controls layer changes.

One UI Language, Three Platforms

The kits are full-screen, click-through recreations of the live game over real city renders. The chrome — panels, buttons, cash pill, minimap — is identical on every surface; only the controls layer swaps: touch joystick + buttons on mobile, keyboard hints on PC, gamepad-glyph prompts on console.

Mobile — in-city HUD with touch joystick, cash pill & minimap; a walk-by Food Shop floats over the live world
PC — 3D-preview Car Showroom with stat bars, equip / drive actions, and keyboard interaction hints
Console — perf-mode Settings with gamepad-glyph prompts (Ⓐ Select · Ⓑ Back · Ⓨ Reset) and a focus ring
Home — buy furniture, then drag it into an isometric room; flip & arrange to decorate

Visual Foundations

The aesthetic is "Bright City-Builder" / Navy HUD — the Adopt-Me / mobile-tycoon family. Everything is soft, glossy, and 3D-ish ("soft-toy" feel); nothing is flat, nothing is a sharp rectangle. Every colour, radius, shadow, gradient, and button behaviour is ported 1:1 from the game's UIKit.luau.

The candy 3D

No flat surfaces. A glossy cap floats 6px above a darker lip, with a soft blurred contact shadow grounding it. Pressing sinks the cap onto the lip (squash to ~0.96); release springs back with a Back-ease overshoot — the brand's signature bounce.

Type — stickered

Fredoka (FredokaOne substitute) for titles, buttons & all numbers; Montserrat (Gotham substitute) for body. Display text carries a 2px outline in the surface's lip colour — the cartoon "sticker" look.

Radii

Panel 20px · card / row / tile 14px · button 13px · pills & toggles fully round · world billboards 10px. Nothing is square.

Motion

Press 70ms Quad-out squash; release 200ms Back-ease spring. Panels pop in from scale 0.82. Currency ticks across to its new value with a quick punch — never a hard snap.

Shadows

Roblox has no box-shadow, so the game offsets a 62%-alpha navy frame downward; that's recreated as a --shadow-panel token. HUD chrome shares one navy bevel with a 4px bottom shadow lip.

Layout

Panels centered on a ~45% dimmed scrim — except walk-by popups, which float over the live world with a transparent backdrop. HUD pinned to corners at a 16px inset. Touch targets never below 44px.

Tokens & Architecture

Token layers

134 tokens across five files — colors, typography, effects (radii / shadows / gloss / motion), spacing, fonts — all @imported by a single styles.css entry point.

Semantic aliasing

Raw brand values (--tl-panel) feed semantic aliases (--surface-panel, --text-money, --accent-quest) — consumers reference intent, not hex.

Iconography

One icon language — the smooth3d set: 41 glossy 3D-rendered PNGs (currency, rewards, navigation, vehicles, food, pets, system), used at natural colour with a soft drop shadow. No flat / line icons, no emoji.

Reverse-engineered

Every value traces to the read-only game source: UIKit.luau for primitives, the real *UI.client.luau screens for layouts, Icons.luau for the icon table, and CarCatalog / FoodMenu for real product copy in the mocks.

Specimen cards

18 Design-System specimen cards document colours, type, radii, spacing, iconography, the brand world, and each component — a living style guide rendered from the same tokens.

Agent-ready

Ships with a SKILL.md and per-component authoring prompts, so the system works as a Claude Code skill — an agent can build new on-brand screens from the tokens.

Content & Voice

  • Voice — second person, breezy, helpful. The shop greets you: "What can we get you?" Confirmations are upbeat and immediate: "Bought Burger!" · "+20 energy".
  • Ruthless length — titles are 1–2 words, item descriptions a single trait line ("Nimble cornering"), buttons a verb or a price. A whole settings explainer is one sentence.
  • Currency — one soft currency, Cash, written $ + comma-grouped ($1,500) and shown as glossy green money. No gems in play.
  • No emoji in UI copy — the playful accents are the 3D icons and candy buttons. Shape badges use a single typographic glyph as a no-asset fallback, never an emoji.
  • Casing — Title or sentence case for titles and buttons; tiny UPPERCASE only for micro-labels and hints.
