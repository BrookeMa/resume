Architecture

AI Game Engine

Host output parsed for structured directives — ASSIGN_ROLE, NEXT_SPEAKER, ELIMINATE, GAME_OVER, [BOARD:Player] — driving the entire game state machine. 15 templates + custom games.

React State

3 Contexts (Auth, Game, GameRoom) with 25 useState calls in the room provider. 11 custom hooks including useHostRound (699 lines) for turn orchestration.

Real-time Multiplayer

Supabase Realtime postgres_changes for state sync. Broadcast channel for TTS audio sharing. Invite-code rooms with clientId dedup and guest fallback polling.

Voice Pipeline

MediaRecorder + Web Audio API (AnalyserNode, 60-bar waveform at 60fps) for STT via Whisper. Cartesia & Inworld TTS with sentence-level queue and typewriter reveal.

UI System

49 components built on shadcn/ui + Radix primitives. CVA variants, tailwind-merge, Motion animations. Mobile drawers with iOS safe-area and 100dvh.

Payments & Auth

Stripe checkout, webhooks, subscriptions, token pay-as-you-go with model-aware cost estimation. Supabase Auth: OAuth, JWT, Row-Level Security.

Performance & Quality

  • Code Splitting — next/dynamic with ssr: false for heavy components (LobbyView, CharacterBrowser, PlayerPanel) to reduce initial bundle.
  • Tree Shaking — optimizePackageImports for Radix UI (20+ packages), Lucide, Recharts, date-fns, Sonner.
  • Re-render Prevention — useMemo / useCallback / ref chains; GameRoomContext value is a single memoized object gating 25+ state values.
  • Image Optimization — AVIF + WebP, 5 device sizes, quality 75/90, 30-day cache TTL.
  • Production Hardening — Console stripping (keeps error/warn), Sentry debug tree-shake, CSP headers (X-Frame-Options DENY, strict Referrer-Policy).
  • Rate Limiting — 30 req / 60s per chat endpoint; token balance pre-checks; AbortController timeouts (30–120s).
  • 131 Test Files — Game engine, host parsing, template drivers, Stripe flows, avatar logic, auth, multiplayer merge, TTS broadcast. Playwright E2E with trace-on-retry.
  • Auth — Supabase JWT + Row-Level Security; getAuthUserFromRequest middleware on every API route.
📄

Key Modules

  • useHostRound.ts 699 lines — Round orchestrator: system prompt → streaming API → directive parsing → speaker queue → retries → pacing → analytics.
  • GameRoomContext.tsx 25 useState — Messages, players, phases, channels, boards, sections, votes, timer, mood, game-over. Local-first with debounced Supabase sync.
  • gm-system-prompt.ts Core — Builds Game Master prompt with directives: ASSIGN_ROLE, NEXT_SPEAKER, ELIMINATE, GAME_OVER, [BOARD], [ACCESS], [SECTION], [MY_NOTES].
  • game-template-driver.ts Core — Per-template mechanics, pacing, speaker order, phase transitions, progression policies.
  • tts-broadcast.ts Real-time — Supabase Broadcast for multiplayer TTS. Owner fetches → broadcasts base64 → guests subscribe. djb2 hash + LRU cache (100 entries).
  • voice.ts Audio — MediaRecorder + AudioContext + AnalyserNode. 60-bar frequency canvas at 60fps via requestAnimationFrame.
  • use-chat-tts.ts Audio — Sentence extraction, per-speaker voice selection, typewriter text reveal synced to playback. 8s timeout fallback.
