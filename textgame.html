// Architecture

How It's Built

⚙

AI Game Engine

The AI Game Master's output is parsed for structured directives — ASSIGN_ROLE, NEXT_SPEAKER, ELIMINATE, GAME_OVER, [BOARD:Player] — that drive the entire game state machine. 15 built-in templates with custom game creation.

★

React Architecture

3 React Contexts (AuthContext, GameContext, GameRoomContext) with 25 useState calls in the room provider. 11 custom hooks including useHostRound (699 lines) orchestrating the entire turn cycle.

⚡

Real-time Multiplayer

Supabase Realtime postgres_changes for state sync. Broadcast channel for TTS audio sharing (owner → guests). Invite-code room joining with clientId deduplication and guest session fallback with 3s polling.

♬

Voice Pipeline

MediaRecorder + Web Audio API (AnalyserNode, getByteFrequencyData, requestAnimationFrame waveform canvas) for STT via Whisper. Cartesia & Inworld TTS with sentence-level queue and typewriter reveal synced to audio.

📦

49 UI Components

shadcn/ui on Radix primitives. class-variance-authority for variants + tailwind-merge. Motion (Framer) entrance animations. Tiptap rich-text editor. Mobile Sheet drawers with iOS safe-area and 100dvh.

💰

Payments & Auth

Stripe checkout, webhooks, subscription management, and token-based pay-as-you-go with model-aware cost estimation. Supabase Auth with OAuth (Google/Facebook), JWT, and Row-Level Security.

// Engineering

Performance & Code Quality

  • Dynamic Imports — next/dynamic with ssr: false for heavy components (LobbyView, CharacterBrowser, PlayerPanelWithBoard) to reduce initial bundle and avoid hydration mismatches.
  • Tree Shaking — optimizePackageImports configured for Radix UI (20+ packages), Lucide React, Recharts, date-fns, Sonner to minimize bundle size.
  • Re-render Prevention — useMemo/useCallback/ref chains throughout context providers; contextValue in GameRoomContext is a single memoized object gating 25+ state values.
  • Image Optimization — AVIF + WebP formats, 5 device sizes, quality 75/90, 30-day cache TTL via Next.js Image.
  • Production Hardening — compiler.removeConsole strips logs (keeps error/warn); Sentry treeshake.removeDebugLogging; CSP headers (X-Frame-Options DENY, strict Referrer-Policy).
  • Rate Limiting — Custom middleware: 30 requests / 60 seconds per chat stream endpoint; token balance pre-checks with AbortController timeouts (30–120s).
  • Testing — 131 test files covering game engine (host output parsing, template drivers, game pace), Stripe flows, avatar logic, auth, multiplayer state merge, TTS broadcast, and UI components. Playwright E2E with Chromium + trace-on-retry.
  • Auth Security — Supabase JWT + Row-Level Security on game_room_state; getAuthUserFromRequest middleware validates Bearer tokens and cookies on every API route.

// Key Modules

Notable Source Files

  • useHostRound.ts 699 lines — Central round orchestrator: builds host system prompt, calls streaming API, parses directives, runs speaker queue, handles retries, pacing, and analytics.
  • GameRoomContext.tsx 25 useState calls — Manages messages, players, phases, channels, boards, sections, votes, timer, mood, game-over state. Local-first persistence with debounced Supabase sync and beforeunload save.
  • gm-system-prompt.ts — Builds the Game Master system prompt with structured directives: ASSIGN_ROLE, NEXT_SPEAKER, ELIMINATE, GAME_OVER, [BOARD:Player], [ACCESS:Channel], [SECTION:Title], [MY_NOTES].
  • game-template-driver.ts — Template-specific game mechanics and progression policies. Adapts pacing, speaker order, and phase transitions per template type.
  • tts-broadcast.ts — Supabase Broadcast for multiplayer TTS audio sharing. Owner fetches TTS → broadcasts base64 → guests subscribe. djb2 hash cache keys with LRU (max 100 entries).
  • voice.ts — useVoiceInput: MediaRecorder + AudioContext + AnalyserNode waveform visualization. 60-bar frequency canvas at 60fps via requestAnimationFrame.
  • use-chat-tts.ts — Sentence extraction, per-speaker voice selection, typewriter-style text reveal synced to audio playback. 8s fallback if TTS stalls.
