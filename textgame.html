Architecture

AI Game Engine

Host output parsed for structured directives — ASSIGN_ROLE, NEXT_SPEAKER, ELIMINATE, GAME_OVER, [BOARD:Player] — driving the game state machine. 16 templates with 80+ phase/role-gated action buttons. Standardised ActionType taxonomy across 9 categories.

React State

3 Contexts (Auth, Game, GameRoom) with 27 useState calls in the room provider. 12 custom hooks including useHostRound (775+ lines) for turn orchestration and useGameActions for phase/role-gated action buttons.

Real-time Multiplayer

Supabase Realtime postgres_changes for state sync. Broadcast channel for TTS audio sharing. Invite-code rooms with clientId dedup and guest fallback polling.

Voice Pipeline

MediaRecorder + Web Audio API (AnalyserNode, 60-bar waveform at 60fps) for STT via Whisper. Cartesia & Inworld TTS with sentence-level queue and typewriter reveal.

UI System

49 components built on shadcn/ui + Radix primitives. CVA variants, tailwind-merge, Motion animations. Mobile drawers with iOS safe-area and 100dvh.

Payments & Auth

Stripe checkout, webhooks, subscriptions, token pay-as-you-go with model-aware cost estimation. Supabase Auth: OAuth, JWT, Row-Level Security.

Action System Architecture

Context-sensitive action buttons replace free-text input with structured game actions. Phase-gated, role-gated, and customisable per game — from the GM chat all the way to in-game Host AI.

Standardised Action Types

9 ActionType categories (attack defend support investigate move social vote use meta) and 5 TargetType (player enemy location item none). Drive UI colour hints and Host interpretation.

3-Layer Resolution

GameConfig (GM-defined via <CONFIG_ACTIONS>) → Template (quickActions in 16 templates) → Category defaults. First non-empty layer wins. 80+ total actions across templates.

Phase & Role Gating

getPhaseType recognises 7 phases: combat exploration rest social day night vote. Actions filtered by matchesPhase + matchesRole each render cycle.

Host AI Awareness

buildActionsSection injects a PLAYER ACTION BUTTONS block into the Host prompt — grouped by phase, showing labels, targets, and role restrictions. Host resolves actions per game rules.

GM Chat Integration

GM outputs <CONFIG_ACTIONS>[…]</CONFIG_ACTIONS> JSON. Parsed by gm-rules-parser.ts, stored in GameConfig.quickActions, carried into the game room.

Dynamic Scene Switching

Host's PHASE: Combat — The Goblin Den auto-renames the sidebar channel via extractSceneName. Combined with ANNOUNCE + MOOD for immersive scene transitions without multi-room complexity.

Performance & Quality

  • Code Splitting — next/dynamic with ssr: false for heavy components (LobbyView, CharacterBrowser, PlayerPanel) to reduce initial bundle.
  • Tree Shaking — optimizePackageImports for Radix UI (20+ packages), Lucide, Recharts, date-fns, Sonner.
  • Re-render Prevention — useMemo / useCallback / ref chains; GameRoomContext value is a single memoized object gating 25+ state values.
  • Image Optimization — AVIF + WebP, 5 device sizes, quality 75/90, 30-day cache TTL.
  • Production Hardening — Console stripping (keeps error/warn), Sentry debug tree-shake, CSP headers (X-Frame-Options DENY, strict Referrer-Policy).
  • Rate Limiting — 30 req / 60s per chat endpoint; token balance pre-checks; AbortController timeouts (30–120s).
  • 124 Test Files — Game engine, host parsing, template drivers, Stripe flows, avatar logic, auth, multiplayer merge, TTS broadcast. Playwright E2E with trace-on-retry.
  • Auth — Supabase JWT + Row-Level Security; getAuthUserFromRequest middleware on every API route.

Key Modules

  • useHostRound.ts 775 lines — Round orchestrator: system prompt → streaming API → directive parsing → speaker queue → retries → pacing → analytics.
  • GameRoomContext.tsx 27 useState — Messages, players, phases, channels, boards, sections, votes, timer, mood, game-over. Local-first with debounced Supabase sync.
  • gm-system-prompt.ts Core — Builds Game Master prompt with directives: ASSIGN_ROLE, NEXT_SPEAKER, ELIMINATE, GAME_OVER, [BOARD], [ACCESS], [SECTION], CONFIG_ACTIONS.
  • host-prompt-builder.ts Core — Assembles Host system prompt: identity, mechanics, pacing, speaker control, directives, and PLAYER ACTION BUTTONS section with phase-grouped actions.
  • useGameActions.ts Hook — 3-layer action resolution: GameConfig → template → category defaults. getPhaseType maps 7 phases; filters by phase + role each render.
  • gm-rules-parser.ts Core — Parses 9 GM control tags including CONFIG_ACTIONS for custom action buttons. Validates JSON, applies incremental rule edits.
  • game-template-driver.ts Core — Per-template mechanics, pacing, speaker order, phase transitions, progression policies.
  • tts-broadcast.ts Real-time — Supabase Broadcast for multiplayer TTS. Owner fetches → broadcasts base64 → guests subscribe. djb2 hash + LRU cache (100 entries).
  • voice.ts Audio — MediaRecorder + AudioContext + AnalyserNode. 60-bar frequency canvas at 60fps via requestAnimationFrame.
  • use-chat-tts.ts Audio — Sentence extraction, per-speaker voice selection, typewriter text reveal synced to playback. 8s timeout fallback.
