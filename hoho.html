Education IM & Electronic Blackboard

A cross-platform instant messaging application for educational institutions, featuring an iOS mobile client, an Electron desktop client, and Bluetooth-paired electronic blackboard integration. Built for seamless teacher-student interaction in the classroom.

Feature Overview

Messaging Core

Rich messaging with text, handwriting, photos, and voice. Supports 1-on-1 direct messages and group channels for classroom collaboration.

Channels & Topics Social

Slack-style channels for organized discussions. Threaded topic mode for focused conversations within channels.

Reactions & Voting Interactive

Slack-inspired message reactions for quick feedback. Built-in polling/voting system for classroom engagement and decision-making.

Electronic Blackboard Hardware

Remote control via QR code scanning or Bluetooth pairing. Video projection, content sync, PPT display, courseware sharing, and recording.

Search Utility

Full-text search across messages, contacts, and channels for quick information retrieval within the platform.

Desktop Client Electron

Cross-platform Electron desktop app with QR-code login, IPC architecture, and feature parity with the mobile client.

Key Responsibilities

  • iOS App Development — Led the full iOS mobile client, including messaging, handwriting input, voice recording, photo sharing, and real-time communication features.
  • Electron Desktop Client — Built the cross-platform desktop app with QR-code login flow and IPC-based architecture for native system integration.
  • Bluetooth Integration — Implemented CoreBluetooth pairing with electronic blackboards, enabling wireless remote control from mobile devices.
  • WebRTC & WebSocket — Integrated real-time audio/video streaming (WebRTC) and persistent message delivery (WebSocket) for classroom scenarios.
  • Slack-inspired Features — Designed and implemented message reactions, threaded topics, channels, and voting — modeled after Slack's UX patterns.
